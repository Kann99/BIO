# Machine Learning for Genomic Data Classification

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# Read Dataset
data = pd.read_csv("genomic_data.csv")

print("Genomic Dataset\n")
print(data)

# Features
X = data[["GeneFeature1", "GeneFeature2"]]

# Target
y = data["Class"]

# Split Dataset
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=1, stratify=y
)

# Create Model
model = RandomForestClassifier(
    n_estimators=100,
    random_state=1
)

# Train Model
model.fit(X_train, y_train)

# Prediction
prediction = model.predict(X_test)

print("\nActual Class")
print(y_test.values)

print("\nPredicted Class")
print(prediction)

# Accuracy
accuracy = accuracy_score(y_test, prediction)

print("\nAccuracy:", round(accuracy * 100, 2), "%")

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

Explanation:

pandas is used to read and manage datasets.

train_test_split divides data into training and testing sets.

RandomForestClassifier creates a Random Forest classification model.

accuracy_score calculates the accuracy of predictions.

Theory: Machine Learning is a branch of Artificial Intelligence that enables computers to learn patterns from data and make predictions.

2. Read Dataset

data = pd.read_csv("genomic_data.csv")

Explanation: Reads the genomic CSV file and stores it in a DataFrame named data.

Theory: A genomic dataset contains biological or genetic information used for analysis. CSV stands for Comma-Separated Values.

3. Display Dataset

print("Genomic Dataset\n")
print(data)

Explanation: Displays the genomic dataset on the screen.

Theory: A DataFrame is a two-dimensional data structure consisting of rows and columns.

4. Select Input Features

X = data[["GeneFeature1", "GeneFeature2"]]

Explanation: Selects GeneFeature1 and GeneFeature2 as input features for the model.

Theory: Features are the input variables used by a machine learning model to identify patterns and make predictions.

5. Select Target Variable

y = data["Class"]

Explanation: Selects the Class column as the target variable.

Theory: The target variable is the output that the model learns to predict. Here, the classes are Healthy and Disease.

6. Split Dataset

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=1, stratify=y
)

Explanation:

train_test_split() divides the dataset into training and testing sets.

test_size=0.3 uses 30% data for testing and 70% for training.

random_state=1 makes the split reproducible.

stratify=y maintains the class proportions in both sets.

Theory: Training data is used to teach the model, while testing data is used to evaluate its performance.

For 10 samples:

Training samples = 7

Testing samples = 3

7. Create Random Forest Model

model = RandomForestClassifier(
    n_estimators=100,
    random_state=1
)

Explanation:

Creates a Random Forest classification model.

n_estimators=100 specifies that the model will use 100 decision trees.

random_state=1 makes the model's random processes reproducible.

Theory: Random Forest is a supervised machine learning algorithm that combines multiple decision trees and uses majority voting to determine the final class.

8. Train the Model

model.fit(X_train, y_train)

Explanation: Trains the Random Forest model using the training features and their corresponding class labels.

Theory: Training is the process in which a machine learning model learns patterns from labelled data.

9. Predict Classes

prediction = model.predict(X_test)

Explanation: Uses the trained model to predict the classes of the testing data.

Theory: Classification assigns data to predefined categories, such as Healthy or Disease.

10. Display Actual Classes

print("\nActual Class")
print(y_test.values)

Explanation: Displays the original class labels of the testing samples.

Theory: Actual classes are the known labels used to compare the model's predictions.

11. Display Predicted Classes

print("\nPredicted Class")
print(prediction)

Explanation: Displays the classes predicted by the Random Forest model.

Theory: Predicted classes are the output labels generated by the trained machine learning model.

12. Calculate Accuracy

accuracy = accuracy_score(y_test, prediction)

print("\nAccuracy:", round(accuracy * 100, 2), "%")

Explanation:

accuracy_score() compares actual and predicted classes.

round() rounds the result to two decimal places.

Multiplication by 100 converts accuracy into a percentage.

Theory: Accuracy measures how many predictions are correct out of all predictions made by the model.

Formula:

Accuracy = (Correct Predictions / Total Predictions) × 100

Important Formulas

1. Training Data Percentage

Training Data = 100% − Testing Data

2. Testing Data Percentage

Testing Data = (Testing Samples / Total Samples) × 100

3. Accuracy

Accuracy = (Correct Predictions / Total Predictions) × 100

4. Error Rate

Error Rate = (Incorrect Predictions / Total Predictions) × 100

5. Precision

Precision = TP / (TP + FP)

6. Recall

Recall = TP / (TP + FN)

7. F1-Score

F1-Score = 2 × (Precision × Recall) / (Precision + Recall)

8. Random Forest Majority Voting

Final Class = Majority Vote of all Decision Trees
